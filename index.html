1. ภาพรวมแอปพลิเคชัน

เครื่องมือนี้เป็น Gantt Chart Planner แบบไฟล์ HTML เดี่ยว ทำงาน Offline 100% บนเบราว์เซอร์ ไม่ต้องติดตั้งโปรแกรมหรือเชื่อมต่อ Cloud ข้อมูลทั้งหมดถูกบันทึกอัตโนมัติไว้ใน localStorage ของเบราว์เซอร์เครื่องนี้เท่านั้น

⚠️ สำคัญ: ข้อมูลผูกกับเบราว์เซอร์/โปรไฟล์เดียว ไม่ sync ข้ามเครื่อง — แนะนำให้ Export เป็น JSON เก็บสำรองเป็นระยะ (ดูหัวข้อ 14)

โครงสร้างหน้าจอหลักแบ่งเป็น 2 ฝั่ง:

  • ฝั่งซ้าย (Sidebar): รายการ Task แบบ Tree เรียงตามลำดับ
  • ฝั่งขวา (Gantt Chart): แสดงแท่งงานตามไทม์ไลน์ พร้อมเส้นเชื่อม Dependency

ทั้งสองฝั่งเลื่อน (scroll) พร้อมกันเสมอ และหัวตารางจะปรับความสูงอัตโนมัติตามจำนวนชั้น Timescale ที่เปิดใช้งาน

4. จัดการ Task ในตารางฝั่งซ้าย

เพิ่ม Task

คลิกปุ่ม + Task มุมขวาบนของตาราง เพื่อเพิ่ม Task ใหม่ที่ระดับบนสุด

แก้ไข Task

คลิกที่ชื่อ Task หรือไอคอนดินสอ (ปรากฏเมื่อ hover แถว) เพื่อเปิดหน้าต่างแก้ไขรายละเอียด: ชื่อ, ประเภท, สี, วันที่เริ่ม-จบ, จำนวนวันทำงาน, สถานะ, Progress %, ผู้รับผิดชอบ, Predecessors และหมายเหตุ

💡 ระหว่างแก้ไขในหน้าต่าง (Modal) ระบบจะ แสดงตัวอย่างการเปลี่ยนแปลงบน Gantt แบบสด (Live Preview) ทันทีที่พิมพ์ — ถ้ากด Cancel ระบบจะคืนค่าดั้งเดิมให้อัตโนมัติ ถ้ากด Save จึงจะบันทึกจริง

สร้าง Sub-task

ทำได้ 2 วิธี:

  1. ลาก & วาง (Drag & Drop): ลากแถว Task ไปวางตรงกึ่งกลาง (25%-75%) ของแถว Task เป้าหมาย เพื่อทำเป็น Sub-task ของแถวนั้น
  2. ปุ่มลัด: ใช้ปุ่ม ⇥ (Indent — ทำเป็น Sub-task ของแถวด้านบน) และ ⇤ (Outdent — ยกออกมาเป็นระดับบน) ที่ปรากฏเมื่อ hover แถว

Progress Mode

  • Manual: กรอกเปอร์เซ็นต์ความก้าวหน้าเอง (ระบบจำกัดค่าไว้ที่ 0-100% เสมอ พิมพ์เกินจะถูกปรับให้อัตโนมัติ)
  • Auto (Rollup): คำนวณ % จากค่าเฉลี่ยของ Sub-task ทั้งหมดโดยอัตโนมัติ — เลือกในหน้าต่างแก้ไข Task

ซ่อน / ลบ

ใช้ไอคอน 👁 (ซ่อนเฉพาะรายการฝั่งซ้าย — เส้น/แถบยังแสดงบน Gantt ตามปกติ, เฉพาะประเภท Mark/Highlight) หรือไอคอนถังขยะเพื่อลบ Task ออกถาวร

5. การทำงานกับแท่ง Gantt

  • ลากย้ายวัน: คลิกค้างที่ตัวแท่ง แล้วลากซ้าย-ขวา เพื่อเลื่อนวันเริ่ม-จบทั้งชุด
  • ยืด/หดระยะเวลา: ลากที่ขอบขวาของแท่ง (เคอร์เซอร์เปลี่ยนเป็นลูกศรปรับขนาด)
  • ดับเบิลคลิก: เปิดหน้าต่างแก้ไขรายละเอียด Task นั้นทันที
  • Hover ที่แท่ง: จะเห็น Tooltip แสดงชื่อ, %, ช่วงวันที่ และจุดลาก Dependency (วงกลมเล็กหัว-ท้ายแท่ง)
ℹ️ ความกว้างของแท่งคำนวณแบบนับวันปฏิทินรวมทั้งวันเริ่มและวันจบ (Inclusive) เช่น เริ่ม-จบวันเดียวกัน = 1 วัน

6. Mark / Milestone / Highlight

ประเภทลักษณะการใช้งาน
♦️ Milestoneจุดสำคัญวันเดียว รูปสี่เหลี่ยมข้าวหลามตัดใช้แทนจุดตรวจรับ/ส่งมอบงาน เชื่อม Dependency ได้เหมือน Task ปกติ
📍 Markเส้นแนวตั้งชี้วันสำคัญ วันเดียวใช้ทำ "วันนี้", วันประชุม ฯลฯ
🟩 Highlightแถบสีคลุมช่วงวันที่บนพื้นหลัง Ganttใช้เน้นช่วงเวลาพิเศษ เช่น ช่วงหยุดโรงงาน

จัดการทั้งหมดได้จากปุ่ม 📍 Marks/Highlights บน Toolbar — เพิ่ม/แก้ไข/ลบ/ซ่อนเฉพาะฝั่งตารางซ้ายได้จากหน้าต่างเดียว

7. การเชื่อม Dependency (Predecessor)

วิธีที่ 1 — ลากเมาส์สร้างเส้นบน Gantt (แนะนำ)

  1. เอาเมาส์ไป Hover ที่แท่งงานต้นทาง จะเห็นจุดวงกลมเล็กปรากฏที่ขอบซ้าย (Start) และขอบขวา (Finish)
  2. คลิกค้างที่จุดวงกลม แล้วลากไปปล่อยบนจุดวงกลมของแท่งงานปลายทาง
  3. ระบบจะกำหนดประเภทเส้นอัตโนมัติตามจุดที่ลาก-ปล่อย:
ลากจากปล่อยที่ประเภทความหมาย
Finish (ขวา)Start (ซ้าย)FSงานปลายทางเริ่มได้หลังงานต้นทางจบ (พบบ่อยที่สุด)
Start (ซ้าย)Start (ซ้าย)SSเริ่มพร้อมกัน
Finish (ขวา)Finish (ขวา)FFจบพร้อมกัน
Start (ซ้าย)Finish (ขวา)SFพบน้อย ใช้ในกรณีพิเศษ

วิธีที่ 2 — พิมพ์ในช่อง Predecessors

ในหน้าต่างแก้ไข Task พิมพ์รูปแบบ รหัสงานตามด้วยประเภท คั่นด้วยจุลภาค เช่น 3FS, 5SS

ลบเส้น Dependency

คลิกที่เส้นบน Gantt Chart (มีพื้นที่คลิกกว้างกว่าเส้นที่มองเห็น เพื่อให้คลิกง่าย) แล้วยืนยันในกล่องที่ปรากฏขึ้น

⚠️ ป้องกันวนลูป (Circular Dependency): ระบบจะบล็อกและแจ้งเตือนทันที ถ้าการเชื่อมเส้นใหม่จะทำให้เกิดการอ้างอิงวนกลับมาที่ตัวเอง (เช่น A ต้องรอ B และ B ต้องรอ A) ไม่ว่าจะสร้างด้วยการลากหรือพิมพ์ก็ตาม

8. Critical Path (CPM)

กดปุ่ม 🎯 Critical Path (CPM) เพื่อเปิด/ปิดการคำนวณ:

  • ระบบคำนวณ Forward Pass (ES/EF) และ Backward Pass (LS/LF) ของทุก Task ตาม Dependency ที่เชื่อมไว้ รองรับ Lag ครบ 4 แบบ (FS/SS/FF/SF)
  • Task ที่มี Total Float = 0 จะถูกไฮไลท์เป็นสีแดง ทั้งแท่งงานและเส้นเชื่อม — คือ "เส้นทางวิกฤต" ที่หากล่าช้าจะกระทบวันจบโครงการทันที
  • แถบข้อมูล (Banner) ด้านบนจะสรุประยะเวลารวมของเส้นทางวิกฤตและจำนวนงานวิกฤตให้ทันที

9. S-Curve (กราฟความก้าวหน้าสะสม)

กดปุ่ม 📈 S-Curve เพื่อแสดงแผงกราฟด้านล่าง Gantt Chart คำนวณความก้าวหน้าสะสมแบบ Duration-Weighted (ถ่วงน้ำหนักตามจำนวนวันทำงานจริงของแต่ละ Task) สะท้อนภาพรวมความคืบหน้าของทั้งโครงการได้แม่นยำกว่าการเฉลี่ย % แบบธรรมดา

10. Baseline Version & Compare

บันทึก Baseline

เมนู ☰ → 📸 Save Baseline Version... เพื่อบันทึก Snapshot วันที่เริ่ม-จบ (Target) ของทุก Task ในขณะนั้น ตั้งชื่อ Version ได้เอง

เปรียบเทียบ

เมนู ☰ → 📜 Baseline History & Compare... เลือก Version ที่ต้องการแล้วกด 👁 เทียบ — Gantt Chart จะแสดงแถบสีม่วงบาง (แผน Baseline) ซ้อนอยู่เหนือแถบสีปกติ (แผนปัจจุบัน) ของทุก Task ให้เห็นความต่างทันที กดปุ่ม ✕ ยกเลิกการเทียบ บนแถบแจ้งเตือนเพื่อออกจากโหมดนี้

ปุ่ม ⤴ Restore ใช้ดึงวันที่จาก Baseline นั้นกลับมาใช้เป็นแผนปัจจุบัน และ ✕ ใช้ลบ Baseline ที่ไม่ต้องการ

ℹ️ ถ้า Task ใดไม่มีอยู่ใน Baseline ที่เลือกเทียบ (เช่น เพิ่ง Task เพิ่มทีหลัง) ระบบจะข้ามไม่แสดงแถบเทียบให้ Task นั้นเฉยๆ ไม่ error

11. ตั้งค่า Timescale (ชั้นแสดงผลปฏิทิน)

ปุ่ม 📅 Timescale Scale เปิดหน้าต่างเลือกเปิด/ปิดแต่ละชั้นอิสระ: Years, Quarters, Months, Weeks, Days — เลือกได้ตั้งแต่ 1 ถึง 5 ชั้นพร้อมกัน ความสูงหัวตารางทั้งฝั่งซ้ายและขวาจะปรับให้ตรงกันอัตโนมัติเสมอไม่ว่าจะเลือกกี่ชั้นก็ตาม

12. เวลาทำงานและวันหยุด (Working Calendar)

ปุ่ม ⚙️ เวลาทำงาน ใช้กำหนด:

  • วันทำงานประจำสัปดาห์ (เช่น จันทร์-ศุกร์)
  • เวลาเริ่ม-เลิกงาน และเวลาพัก (Break Time)

ค่านี้ถูกใช้คำนวณ "จำนวนวันทำงาน (Weekdays)" ในหน้าต่างแก้ไข Task และการคำนวณ CPM ที่จะข้ามวันหยุดโดยอัตโนมัติ

13. Zoom และช่วงวันที่แสดงผล

ใช้ปุ่ม วัน/สัปดาห์/เดือน/ไตรมาส เพื่อปรับความกว้างต่อวันอย่างรวดเร็ว หรือกำหนดช่วงวันที่ต้องการโฟกัสในกล่อง "ช่วงวันที่" แล้วกด ใช้ช่วงนี้ — กด Auto-fit เพื่อให้ระบบคำนวณช่วงที่ครอบคลุม Task ทั้งหมดให้อัตโนมัติ

14. Import / Export / พิมพ์เอกสาร

ฟังก์ชันรายละเอียด
💾 Export as JSONสำรองข้อมูลครบทุกส่วน (Task, Baseline History, Working Calendar, Timescale) — ใช้ไฟล์นี้ Import กลับเพื่อย้ายเครื่อง/สำรองข้อมูล
📂 Import JSON / CSVโหลดไฟล์ JSON ที่เคย Export กลับเข้าระบบ (แทนที่ข้อมูลปัจจุบันทั้งหมด)

15. ข้อจำกัดที่ควรรู้

  • ข้อมูลอยู่ใน localStorage ของ เบราว์เซอร์/เครื่องเดียว เท่านั้น ไม่ sync ข้ามอุปกรณ์ — ควร Export JSON สำรองเป็นระยะ โดยเฉพาะก่อนล้าง Cache เบราว์เซอร์หรือเปลี่ยนเครื่อง
  • การแก้ไขในหน้าต่าง Modal จะแสดงผลสดบน Gantt ทันที — หากมี Task จำนวนมาก (หลักร้อยขึ้นไป) การพิมพ์อาจมีอาการหน่วงเล็กน้อยขณะพิมพ์เร็วๆ
  • บนหน้าจอขนาดเล็ก จุดลาก Dependency ของ Milestone (Start/Finish) อยู่ใกล้กันมาก อาจต้องซูมหรือคลิกอย่างระมัดระวัง

16. คำถามที่พบบ่อย (FAQ)

Q: ข้อมูลหายหลังปิดเบราว์เซอร์ ทำอย่างไร?
A: ตรวจสอบว่าเปิดไฟล์ HTML เดิม (path เดิม) ในเบราว์เซอร์เดิมที่เคยบันทึกไว้ และไม่ได้เปิดโหมด Incognito/Private ซึ่งจะไม่บันทึก localStorage ถาวร

Q: ทำไมลากสร้างเส้น Dependency ไม่ติด?
A: ต้องลากเริ่มจากจุดวงกลมที่ขอบแท่งงานเท่านั้น (ไม่ใช่ตัวแท่งเอง) และปล่อยเมาส์ให้ตรงจุดวงกลมของแท่งปลายทางพอดี

Q: ทำไมบันทึก Dependency ไม่ได้ ขึ้นเตือน Circular Dependency?
A: การเชื่อมที่พยายามทำจะทำให้เกิดการอ้างอิงวนกลับมาที่งานเดิม ให้ตรวจสอบสายงานที่มีอยู่แล้วก่อนเชื่อมใหม่

Q: พิมพ์ออกมาแล้วตัวเล็ก/ไม่พอดีหน้ากระดาษ?
A: ตรวจสอบว่าตั้งค่าเครื่องพิมพ์เป็น A4 แนวนอน (Landscape) และปิดตัวเลือก "Scale/Fit to page" ของเบราว์เซอร์ เพราะระบบจัดขนาดให้พอดีอัตโนมัติอยู่แล้ว
